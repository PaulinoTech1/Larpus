Reviewed 2026-10-09. Claude Pro is the individual paid Claude chat plan, listed at USD 20/month in the US. It gives more usage than Free, priority access, early features, Claude Code access and longer multistep tasks. Annual billing can be discounted; local currencies, regional taxes and store prices vary. Pro does not include Claude Console API usage: API access and charges are separate. Usage depends on message/file/conversation length and chosen model or feature; five-hour session limits and weekly limits apply, with other caps possible. A subscription does not guarantee unlimited use or any particular account's model availability. This dated official-reference brief is not a Claude connection in Larpus.
