Ubuntu initial general-availability kernel comparison: Ubuntu 24.04 LTS shipped Linux 6.8; Ubuntu 25.04 shipped Linux 6.14; Ubuntu 26.04 LTS shipped Linux 7.0. These are GA release baselines, not a promise about an installed system or later updates. Hardware Enablement (HWE), OEM and vendor-specific kernel packages can differ. Check the exact distribution point release and kernel package build when comparing hardware support. This reviewed comparison uses the three official Ubuntu release-note snapshots; it does not imply that Ubuntu 25.04 remains supported.
