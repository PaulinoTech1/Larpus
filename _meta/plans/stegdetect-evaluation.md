# Evaluation criteria before implementation
Track Stegdetect and combined input gate separately. Calculate TP/FP/TN/FN only for conclusive scans; errors and incomplete scans must not earn detection credit. Show denominators, null undefined rates, per-family results, exact dataset/scanner fingerprints and append-only local history. Reports must omit sample text. Reject invalid/duplicate labels. Synthetic labels are authored, not independent real-world evidence. Coverage gaps must remain visible. Review the tracker independently before making stronger security claims. No detector tuning, dependency change, deployment or commit is authorized.
