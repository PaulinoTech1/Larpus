# Role-specific skill catalog

Five locally authored specialist skills per role (60 total). Existing shared skills remain available. Select one skill in the HUD; selecting a new persona or skill starts a fresh conversation. Skills coach reasoning and communication, without adding tools or claiming professional credentials.

## Home assistant

- [Daily planning](../skills/home-day-plan/SKILL.md): Plan a day around energy, deadlines and dependencies.
- [Household routines](../skills/home-household-routines/SKILL.md): Build realistic recurring household checklists.
- [Meal preparation](../skills/home-meal-prep/SKILL.md): Plan meals from owner-supplied ingredients and constraints.
- [Everyday explanations](../skills/home-explain-reference/SKILL.md): Explain an unfamiliar everyday topic with useful analogies.
- [Fictional character workshop](../skills/home-character-workshop/SKILL.md): Prepare an original character for a fictional setting.

## IT / cyber LARP coach

- [IT interview rehearsal](../skills/cyber-interview-rehearsal/SKILL.md): Rehearse evidence-based IT and cybersecurity interview answers.
- [Incident tabletop](../skills/cyber-incident-tabletop/SKILL.md): Rehearse defensive incident triage in a fictional organisation.
- [Threat modelling](../skills/cyber-threat-modelling/SKILL.md): Map trust boundaries and defensive controls for a scoped design.
- [Identity access review](../skills/cyber-identity-review/SKILL.md): Practise least-privilege and identity lifecycle reasoning.
- [Defensive lab debrief](../skills/cyber-lab-debrief/SKILL.md): Turn an authorised defensive lab into a reproducible learning record.

## Linux Kernel Expert

- [Kernel crash triage](../skills/kernel-crash-triage/SKILL.md): Reason about owner-supplied oops, panic and stack traces.
- [Kernel concurrency review](../skills/kernel-concurrency/SKILL.md): Review locking, lifetime and memory-order reasoning.
- [Kernel memory analysis](../skills/kernel-memory/SKILL.md): Explain allocation constraints and memory pressure.
- [Driver lifecycle review](../skills/kernel-driver-review/SKILL.md): Review a supplied driver's probe, I/O and teardown lifecycle.
- [Kernel configuration trade-offs](../skills/kernel-config-tradeoffs/SKILL.md): Assess a proposed kernel configuration change on paper.

## System Administrator

- [Enterprise change planning](../skills/sysadmin-enterprise-change/SKILL.md): Prepare an enterprise change with owners, rollback and acceptance gates.

- [Backup and recovery planning](../skills/sysadmin-backup-recovery/SKILL.md): Plan enterprise backups against stated RPO and RTO.

## Network Engineer

- [Packet path troubleshooting](../skills/network-packet-path/SKILL.md): Trace a supplied connectivity failure through network layers.

- [Routing and resilience](../skills/network-routing-resilience/SKILL.md): Reason about routing choices and failure convergence.

- [DNS and service discovery](../skills/network-dns-services/SKILL.md): Diagnose name resolution and service discovery.
