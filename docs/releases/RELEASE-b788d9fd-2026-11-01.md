## What changed

This release changes **data only**. Code, prompts, tests, scripts, evals and
deploy files are the same as in `1022de11`.

- **How it was built.** The checkout had uncommitted code changes, so the release
  was not staged from it. A separate source tree was built from the **exact 497
  frozen files of `1022de11`** plus the current data files. It was staged with
  `python scripts/releases.py stage --source <tree>`. `research/catalog.json`
  was in that tree only for the stage provenance check; `research/` is not part
  of a release payload.
- **The 10 changed files** (same 497 paths otherwise):
  - `knowledge/approved.sqlite`
  - `knowledge/manifest.json`
  - `knowledge/embeddings.npy`
  - `knowledge/embeddings-rowids.npy`
  - `knowledge/embeddings-manifest.json`
  - `knowledge/notes.sqlite`
  - `knowledge/notes-manifest.json`
  - `knowledge/provenance.json`
  - `knowledge/authors.json`
  - `config/reference-reviews.json`
- **Images.** The broker and notes images are identical to `1022de11`. The
  agent image was rebuilt because it copies in `knowledge/`.
- **Left out on purpose.** These checkout changes are not in the release:
  - `runtime/knowledge.py` `retrieval_question()`/`PLATFORMS`, which is flagged
    by the attribution plan for separate evaluation;
  - `web/app.js` broker-refusal text;
  - the newer `prepare-knowledge.py`, `research_policy.py` and
    `mtrageval_local.py`;
  - the eval fixture changes and six test files.
