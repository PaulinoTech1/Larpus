# Owner review for mathematics and quantum references

Extraction can contain unusual notation and font/control encodings. The ordinary
screen runs first. Held passages receive an owner-local report showing the exact
text, PDF page, reason and Unicode inventory. No model automatically approves them.
The owner compares passages with the original and explicitly accepts or rejects
them. Acquisition permission, equation accuracy and screening approval are distinct.

For approved references, `config/reference-reviews.json` pins source identity,
original checksum, exact passage/window text hashes, reviewer, date and reason.
Runtime reference loading still performs the normal screen, but permits those exact
reviewed strings for specified Unicode/control findings. Scanner unavailability,
unrelated sources, changed text and instruction-override/role-spoof patterns fail.
User conversation and generated output never use this exception path. Review
receipts are source configuration, not a user-supplied permission channel.

On October 14 the owner approved all 52 held Chicone passages. The original and
held report remain private, with extraction warnings preserved. Admission appends
to the checkout index and workload queue; the frozen production release is unchanged.
The running generation pass keeps its initial queue; new windows become available
on a subsequent pass. Completed note keys are retained. New originals need staged
release integration before live chat retrieves them.

See [the false-positive review](CHICONE_SCREENING_REVIEW.md) for the 19 control
holds, 33 mixed Unicode/incomplete-scan holds and owner-adjudication limitations.

This records human acceptance, not independent mathematical verification or a
guarantee against concealed instructions. No global reduction in screening is made.
Future mathematics or quantum documents follow the same report/review/pin workflow;
being mathematical alone never grants approval. The knowledge module's import
allowance increases from seven to eight for this narrow reference-review boundary.

The [mathematical symbol review ledger](MATHEMATICS_SYMBOL_REVIEW.md) records Salsa's
106 complete mixed-script holds and the seven Greek letters involved. Pattern
recognition helps human review; only exact source/text approvals grant exceptions.
